# 微分几何技能手册

## 领域边界与路由约定

- 适用范围：曲线/曲面弧长、Frenet 标架、基本形式、曲率、测地线、主曲率和 Gauss–Bonnet。
- 不接管：三角形、圆、相切、角平分线等初等几何转非基础及进阶课程；圆周上受限 Laplacian 按数学分析题处理。
- 验证契约：先声明参数化、度量和法向方向，再检查符号约定、正则性与坐标不变性。

## 高频错误与口径约定（评委反馈 2026-07-07）

- **法曲率符号约定（必须遵守）**：法曲率 $\kappa_n=\mathrm{II}(w,w)/\mathrm{I}(w,w)$ 的符号取决于单位法向量的选取。本题库对圆柱、球面等经典曲面采用**外法向**约定。圆柱面 $\mathbf{r}(u,v)=(\cos v,\sin v,u)$ 取外法向 $\mathbf{n}=(\cos v,\sin v,0)$，此时 $L=\mathbf{r}_{uu}\cdot\mathbf{n}=0$、$N=\mathbf{r}_{vv}\cdot\mathbf{n}=-1$：沿 $u$ 方向（直母线）$\kappa_n=0$，**沿 $v$ 方向（圆周）$\kappa_n=-1$**（曲面向外法向的反方向弯曲，取负）。
- 若按 $\mathbf{n}=\mathbf{r}_u\times\mathbf{r}_v/|\mathbf{r}_u\times\mathbf{r}_v|$ 算出的是内法向（指向轴线/球心），必须翻转法向（等价于结果变号）后再报答案。
- 高斯曲率 $K=\kappa_1\kappa_2$ 与法向选取无关；平均曲率 $H$ 和单个方向的 $\kappa_n$ 随法向翻转而变号——答题时先写明所取法向再给数值。

## 1 曲线弧长

### 核心定义定理

**曲线弧长**是曲线最基本的几何量。对于参数曲线 `r(t) = (x(t), y(t), z(t))`, `t ∈ [a, b]`, 弧长为切向量模长在区间上的积分。

弧长参数化（自然参数化）是微分几何的核心工具——以弧长 `s` 为参数时，切向量恒为单位向量，Frenet 公式形式最简洁。

### 核心公式

| 情形 | 公式 |
|------|------|
| 空间曲线 `r(t)` | `L = ∫_a^b |r'(t)| dt` |
| 平面曲线 `r(t) = (x(t), y(t))` | `L = ∫_a^b √(x'(t)² + y'(t)²) dt` |
| 弧长参数 `s(t)` | `s(t) = ∫_{t₀}^t |r'(τ)| dτ` |

### 标准化分步解题流程

1. 计算切向量 `r'(t)`
2. 计算切向量模长 `|r'(t)| = √(x'(t)² + y'(t)² + z'(t)²)`
3. 对模长在区间 `[a, b]` 上积分

### 考试高频陷阱

- 忘记开平方根：`|r'|` 是各分量平方和的算术平方根
- 忽略被积函数的绝对值处理（如 `cos u` 在积分区间变号）

### 应试解题技巧

- 先简化被积函数再积分：常见三角函数平方和形式 `sin²t + cos²t = 1`
- 螺旋线 `(cos t, sin t, t)` 的弧长直接为 `√2 · 区间长度`

## 2 平面曲线曲率

### 核心定义定理

**曲率** `κ` 刻画曲线偏离直线的程度。几何意义：曲率是切向量方向角对弧长的变化率，也是密切圆半径的倒数。

### 核心公式

| 情形 | 公式 |
|------|------|
| 平面曲线 `r(t) = (x(t), y(t))` | `κ = |x'y'' - x''y'| / (x'² + y'²)^(3/2)` |
| 函数图 `y = f(x)` | `κ = |f''(x)| / (1 + (f'(x))²)^(3/2)` |
| 极坐标 `r = r(θ)` | `κ = |r² + 2(r')² - rr''| / (r² + (r')²)^(3/2)` |

### 标准化分步解题流程

1. 计算 `r'(t)` 和 `r''(t)`
2. 计算 `r' × r''`（二维中为标量叉积 `x'y'' - x''y'`）
3. 计算 `|r'|`
4. 代入 `κ = |r' × r''| / |r'|³`

### 考试高频陷阱

- 对弧长参数化曲线，`κ = |r''(s)|`，但一般参数化不能直接用此简化
- 二维叉积是标量 `x₁y₂ - x₂y₁`，注意符号但取绝对值

### 应试解题技巧

- 圆 `(R cos t, R sin t)` 曲率恒为 `1/R`，可作为验算基准
- 记住平面曲线 `κ > 0` 恒成立（取绝对值后）

## 3 Frenet标架与单位切向量

### 核心定义定理

**Frenet 标架** `{T, N, B}` 是空间曲线上的活动正交标架：
- **单位切向量** `T = r'(t) / |r'(t)|`
- **主法向量** `N = T'(t) / |T'(t)|`（指向曲率中心方向）
- **副法向量** `B = T × N`

`T, N, B` 构成右手正交系，是研究空间曲线局部性质的基础。

### 核心公式

- `T(t) = r'(t) / |r'(t)|`
- `B(t) = (r'(t) × r''(t)) / |r'(t) × r''(t)|`
- `N(t) = B(t) × T(t)`

### 标准化分步解题流程

1. 计算切向量 `r'(t)`
2. 计算模长 `|r'(t)|`
3. 单位化得 `T = r'(t) / |r'(t)|`
4. 代入指定参数值

### 考试高频陷阱

- 忘记单位化：直接拿 `r'(t)` 当单位切向量
- `N` 的计算需要求导 `T'` 再单位化，不能直接对 `r''` 单位化

### 应试解题技巧

- `T` 的方向只与 `r'(t)` 的各分量比例有关，可在代入参数值后再单位化
- 向量 `(1,2,3)/√14` 形式中，分母是模长，分子是 `r'` 的分量

## 4 空间曲线曲率

### 核心定义定理

空间曲线在一点处的弯曲程度由**曲率** `κ` 度量。与平面曲线不同，空间曲线的曲率只反映弯曲大小，不包含扭转信息。

### 核心公式

| 情形 | 公式 |
|------|------|
| 一般参数化 `r(t)` | `κ = |r'(t) × r''(t)| / |r'(t)|³` |
| 弧长参数 `r(s)` | `κ = |r''(s)| = |T'(s)|` |
| 二维退化 | `κ = |x'y'' - x''y'| / (x'² + y'²)^(3/2)` |

### 标准化分步解题流程

1. 计算 `r'(t)` 和 `r''(t)`
2. 计算向量叉积 `r' × r''`
3. 计算叉积模 `|r' × r''|`
4. 计算 `|r'(t)|` 并取三次方
5. `κ = |r' × r''| / |r'|³`

### 考试高频陷阱

- 叉积计算后模长取平方根时遗漏系数
- 未注意 `r''` 各分量的符号对叉积结果的影响

### 应试解题技巧

- 叉积用行列式计算：`r' × r'' = det([i, j, k; x', y', z'; x'', y'', z''])`
- 螺旋线 `(a cos t, a sin t, bt)` 的曲率为 `κ = a / (a² + b²)`

## 5 挠率

### 核心定义定理

**挠率** `τ` 度量空间曲线偏离平面的程度——它反映副法向量 `B` 沿曲线的旋转速率。τ ≡ 0 当且仅当曲线为平面曲线。

### 核心公式

| 情形 | 公式 |
|------|------|
| 一般参数化 `r(t)` | `τ = (r' × r'')·r''' / |r' × r''|²` |
| 弧长参数 `r(s)` | `τ = -B'(s)·N(s)` |

### 标准化分步解题流程

1. 依次计算 `r'(t)`、`r''(t)`、`r'''(t)`
2. 计算叉积 `r' × r''`
3. 计算三重积 `(r' × r'')·r'''`
4. 计算 `|r' × r''|²`
5. `τ = (r' × r'')·r''' / |r' × r''|²`

### 考试高频陷阱

- 将三重积与叉积模混淆：分子是标量三重积，分母是叉积模的平方
- 忘记 `r'''` 的符号——对正弦余弦求导三次可能出错

### 应试解题技巧

- 螺旋线 `(a cos t, a sin t, bt)` 的挠率 `τ = b / (a² + b²)`
- 如果 `r''' = 0`（如多项式不超过二次），挠率必为零
- 常数曲率和挠率（螺旋线）是最简单实用的验证模型

## 6 第一基本形式

### 核心定义定理

**第一基本形式**（度量形式）定义曲面上的内积结构，用于计算曲面上曲线的弧长、夹角和曲面面积。

`I = ds² = E du² + 2F du dv + G dv²`

其中 `E = r_u·r_u`，`F = r_u·r_v`，`G = r_v·r_v`。

### 核心公式

- `E = r_u·r_u`
- `F = r_u·r_v`
- `G = r_v·r_v`
- 面积元 `dA = √(EG - F²) du dv`

### 标准化分步解题流程

1. 计算偏导向量 `r_u = ∂r/∂u` 和 `r_v = ∂r/∂v`
2. 计算内积得 `E, F, G`
3. 表达为 `ds² = E du² + 2F du dv + G dv²`

### 考试高频陷阱

- `F` 可能是零（正交参数化），但不要预先假设
- `G` 中 `cos u` 的平方不要漏掉
- 球面参数化中 `E` 和 `G` 量纲一致但形式不同

### 应试解题技巧

- 正交参数化时 `F = 0`，计算量大减
- 球面第一基本形式：`E = R², F = 0, G = R² cos² u`

## 7 第二基本形式

### 核心定义定理

**第二基本形式**描述曲面在一点处偏离切平面的程度，即曲面的"弯曲方式"。

`II = L du² + 2M du dv + N dv²`

其中 `L = r_uu·n`，`M = r_uv·n`，`N = r_vv·n`，`n` 为单位法向量。

### 核心公式

- `n = (r_u × r_v) / |r_u × r_v|`
- `L = r_uu · n`
- `M = r_uv · n`
- `N = r_vv · n`

### 标准化分步解题流程

1. 计算 `r_u, r_v`
2. 计算单位法向量 `n = (r_u × r_v) / |r_u × r_v|`
3. 计算二阶偏导 `r_uu, r_uv, r_vv`
4. 分别与 `n` 点积得 `L, M, N`

### 考试高频陷阱

- 忘记对法向量单位化，直接用 `r_u × r_v` 代替 `n`
- `r_uv` 是混合偏导，不等于零不要跳过
- **法向量朝向与面可见性冲突**：几何问题中若涉及凸多面体的"面可见性"判断，本质上是法向量与视线方向的内积符号问题——面 $F$ 在视线方向 $\mathbf{v}$ 下可见当且仅当 $\mathbf{n}_F\cdot\mathbf{v}<0$（外法向朝向观察者）。若曲面的局部法向量选取与多面体整体外法向不一致，可见性判定会完全颠倒。
- **法向量分离定理的误用**：凸多面体的两个可见面在法向量空间中由某个过原点的超平面严格分离，但此结论仅对闭凸多面体成立。若曲面有"凹角"（内法向在某方向的分量不单调），分离性不再成立，不能直接套用。

### 应试解题技巧

- 若 `r_u` 与 `r_v` 正交，法向量计算简化
- 圆柱面 `(R cos v, R sin v, u)`：`L = 0, M = 0, N = R`
- **法向量符号约定的快速判定**：$\mathbf{r}_u\times\mathbf{r}_v$ 给出的是按参数化自然定向的法向量，但在曲面局部微分几何中，法向量的符号选择取决于问题需求。判定技巧——对封闭曲面（如球面），向外指的法向量使高斯曲率 $K>0$ 对应椭圆点的局部严格凸性；向内指则改变第二基本形式的整体符号。若问题涉及"法向量分离"或"凸性判定"，先明确法向是内法向还是外法向，再代入后续计算。
- **凸多面体面可见性的法向量判据**：对于凸多面体，给定视线方向 $\mathbf{v}$，面 $F$ 可见当且仅当 $\mathbf{n}_F\cdot\mathbf{v}<0$（外法向指向观察者一侧）。该判据可推广到光滑凸曲面的切平面可见性——当曲面局部由参数化 $\mathbf{r}(u,v)$ 给出且取外法向时，点 $(u,v)$ 在方向 $\mathbf{v}$ 下可见当且仅当 $\mathbf{n}(u,v)\cdot\mathbf{v}<0$。解题时先算出法向量场，再验证所选法向与问题陈述的"外"/"内"一致性。

## 8 法曲率

### 核心定义定理

**法曲率** `κ_n` 是曲面在给定切方向上弯曲程度的度量。它是曲面沿该方向的截面曲线的曲率在法向量上的投影。

### 核心公式

- `κ_n = II / I = (L du² + 2M du dv + N dv²) / (E du² + 2F du dv + G dv²)`
- 沿 `u` 方向（`dv = 0`）：`κ_n = L / E`
- 沿 `v` 方向（`du = 0`）：`κ_n = N / G`

### 标准化分步解题流程

1. 计算该方向的第一、第二基本形式系数
2. 确定方向比 `du : dv`
3. 代入 `κ_n = II / I`

### 考试高频陷阱

- 混淆法曲率与主曲率：法曲率依赖于方向，主曲率是极值
- 符号约定：不同教材法曲率符号可能不同

### 应试解题技巧

- 母线的法曲率为零（直纹面特性）
- 截面圆方向法曲率等于主曲率之一

## 9 高斯曲率

### 核心定义定理

**高斯曲率** `K` 是曲面内蕴几何最重要的量。`K = κ₁κ₂`，即两个主曲率的乘积。

高斯绝妙定理：高斯曲率仅由第一基本形式决定（内蕴量）。

### 核心公式

- `K = (LN - M²) / (EG - F²)`（用基本形式系数）
- `K = κ₁ · κ₂`（用主曲率）
- 可展曲面 `⇔ K ≡ 0`

### 标准化分步解题流程

1. 计算第一基本形式系数 `E, F, G`
2. 计算第二基本形式系数 `L, M, N`
3. 代入 `K = (LN - M²) / (EG - F²)`

### 考试高频陷阱

- 忘记分母 `EG - F²`——这是面积元平方，不能遗漏
- `LN - M²` 的符号决定曲面的局部形状

### 应试解题技巧

- `K > 0`：椭圆点（局部凸），`K < 0`：双曲点（马鞍形），`K = 0`：抛物点或平坦点
- 圆柱面 `K = 0`，球面 `K = 1/R²`（常正曲率）

## 10 平均曲率与极小曲面

### 核心定义定理

**平均曲率** `H = (κ₁ + κ₂)/2`，是主曲率的算术平均值。

**极小曲面**是平均曲率恒为零的曲面。悬链面、螺旋面是经典极小曲面。

### 核心公式

- `H = (EN - 2FM + GL) / (2(EG - F²))`
- 极小曲面条件：`H = 0` ⇔ `LG - 2MF + NE = 0`
- `H = (κ₁ + κ₂)/2`

### 标准化分步解题流程

1. 计算第一、第二基本形式系数
2. 代入 `H = (EN - 2FM + GL) / (2(EG - F²))`
3. 化简看是否为零

### 考试高频陷阱

- 误将 `EN - 2FM + GL` 当作分子而遗忘分母
- 忽略 `F` 和 `M` 的非零可能性

### 应试解题技巧

- 验证极小曲面用 `LG - 2MF + NE = 0`，避免分母运算
- 悬链面 `r = (cosh u cos v, cosh u sin v, u)` 是标准的极小曲面例子

## 11 曲面面积

### 核心定义定理

曲面面积通过第一基本形式的面积元积分计算。

### 核心公式

- 面积元 `dA = √(EG - F²) du dv`
- 曲面面积 `A = ∬_D √(EG - F²) du dv`

### 标准化分步解题流程

1. 计算 `E, F, G`
2. 计算 `√(EG - F²)`
3. 确定参数域 `D`
4. 进行二重积分

### 考试高频陷阱

- 积分区域参数范围弄错（球面参数 `u ∈ [-π/2, π/2]`，不是 `[0, π]`）
- 忘记 `cos u` 在 `[-π/2, π/2]` 上非负，不需要绝对值

### 应试解题技巧

- 球面面积 `4πR²` 可作为验算基准
- 先对简单变量积分（先 `v` 后 `u`）
- **面积平分线的参数扫描法**：对于凸多边形面积平分问题，核心技巧是参数化所有过顶点的"面积平分线"。设凸多边形顶点按逆时针排列为 $P_1,P_2,\ldots,P_n$，总面积为 $A$。对于每条过顶点 $P_i$ 的射线 $P_i+\lambda(\cos\theta,\sin\theta)$（$\lambda\ge0$），计算该射线在凸多边形内部的线段扫过的面积 $S(\theta)$。关键观察：当 $\theta$ 单调递增时，$S(\theta)$ 在某个区间内连续变化，使得存在唯一的 $\theta$ 使 $S(\theta)=A/2$。这种"角度扫描参数化 + 中间值定理"的方法避免了复杂的解析积分。
- **落边分布的对称性观察**：凸多边形的面积平分线若不过顶点，则其在多边形两对边上的"落点"满足对称的面积分割比。给定凸多边形 $Q$ 和方向 $\mathbf{d}$，所有与该方向平行的面积平分线构成一族平行线，它们在边界上的落点由求解线性方程 $A$（截线左侧）= $A/2$ 确定。当多边形具有轴对称时，该族平分线的落边分布也呈现相应对称性，可大幅减少枚举计算量。
- **曲面面积元积分中的对称性简化**：对于具有旋转对称性的曲面（如环面、球面），先固定对称方向（通常是对 $v$ 的积分），将被积函数化简后再处理单调方向。面积元 $\sqrt{EG-F^2}$ 在对称方向上往往为常数。

## 12 测地线与测地曲率

### 核心定义定理

**测地线**是曲面上"最直"的曲线——其测地曲率 `κ_g ≡ 0`。球面上的大圆、圆柱面上的螺旋线都是测地线。

**测地曲率** `κ_g` 是曲线曲率向量在曲面切平面上的投影的长度。

### 核心公式

- 测地线方程：`κ_g = 0`
- `κ_g = |(r' × r'') · n| / |r'|³`（曲面上曲线的测地曲率公式）

### 标准化分步解题流程

1. 验证曲线是否在曲面上
2. 计算曲线的 `r'`、`r''` 和曲面的法向量 `n`
3. 计算 `κ_g` 或判断是否为零

### 考试高频陷阱

- 测地曲率为零不意味着曲线曲率为零（大圆在球面上曲率非零但测地曲率为零）
- 测地线≠最短路径（局部最短是测地线，但测地线不一定最短）

### 应试解题技巧

- 球面的大圆（过球心的平面与球面交线）一定是测地线
- 测地线方程验证困难时，利用对称性判断

## 13 主曲率

### 核心定义定理

**主曲率** `κ₁, κ₂` 是法曲率在两个主方向上的极值。主曲率满足 `K = κ₁κ₂`，`H = (κ₁ + κ₂)/2`。

**脐点**：`κ₁ = κ₂` 的点（球面上的所有点均为脐点）。

### 核心公式

- 由 `(EG - F²)κ² - (EN - 2FM + GL)κ + (LN - M²) = 0` 求解
- 或用 Weingarten 变换矩阵的特征值

### 标准化分步解题流程

1. 计算基本形式系数
2. 构建 `κ` 的二次方程
3. 求解得 `κ₁, κ₂`
4. 验证 `K = κ₁κ₂` 和 `H = (κ₁+κ₂)/2`

### 考试高频陷阱

- 忘记二次项系数 `(EG - F²)` 可能不为1
- 特征值方向与坐标线方向不一致时混淆

### 应试解题技巧

- 在脐点处，任意方向都是主方向
- 计算主曲率优先用公式，避免直接解二次方程

## 14 渐近线与双曲点

### 核心定义定理

**渐近方向**是法曲率为零的切方向。**渐近曲线**是每点切方向为渐近方向的曲线。

**双曲点** (`K < 0`) 存在两个不同的渐近方向。**椭圆点** (`K > 0`) 无实渐近方向。**抛物点** (`K = 0`) 有一个渐近方向。

### 核心公式

- 渐近方向条件：`L du² + 2M du dv + N dv² = 0`
- 双曲点判定：`LN - M² < 0` ⇔ `K < 0`

### 标准化分步解题流程

1. 计算 `L, M, N`
2. 写出 `L du² + 2M du dv + N dv² = 0`
3. 求解 `du:dv` 的比例关系

### 考试高频陷阱

- 将第一基本形式与第二基本形式混淆
- 渐近方向是切方向，不是曲面上的曲线

### 应试解题技巧

- 双曲抛物面 `z = x² - y²` 在原点处 `K = -4`，渐近方向为 `du = ±dv`
- 使用对称性快速求出渐近方向

## 15 挠率与平面曲线判定

### 核心定义定理

曲线为平面曲线 ⇔ 挠率恒为零（τ ≡ 0）。几何意义：副法向量 `B` 为常向量，曲线全部位于其密切平面内。

### 核心公式

- τ ≡ 0 ⇒ 曲线是平面曲线
- 平面方程由曲线上三点或由 `r(t)` 各分量关系确定

### 标准化分步解题流程

1. 计算 `r'(t)`, `r''(t)`, `r'''(t)`
2. 计算 `τ = (r' × r'')·r''' / |r' × r''|²`
3. 若 τ ≡ 0，观察或求解满足所有点的线性关系 `ax + by + cz = d`

### 考试高频陷阱

- 只验证了一个点的挠率为零，而不是所有点
- 多项式曲线 `r''' = 0` 但 `r' × r''` 也可能为零（退化情况）

### 应试解题技巧

- `r''' ≡ 0` 且 `r' × r''` 不恒为零时，τ ≡ 0 得证
- 找出曲线上三个不共线的点确定平面

## 16 Frenet-Serret公式

### 核心定义定理

Frenet-Serret 公式是空间曲线理论的核心微分方程：

```
T' = κN
N' = -κT + τB
B' = -τN
```

### 核心公式

对弧长参数 `s`：
- `T'(s) = κ(s) N(s)`
- `N'(s) = -κ(s) T(s) + τ(s) B(s)`
- `B'(s) = -τ(s) N(s)`

### 标准化分步解题流程

1. 验证 `|r'(s)| = 1`（确认弧长参数化）
2. `κ = |r''(s)|`
3. `T = r'`, `N = r''/κ`, `B = T × N`
4. `τ = (r' × r'')·r''' / κ²`

### 考试高频陷阱

- 公式只对弧长参数有效，一般参数需要变换
- 符号记忆：`N'` 中有 `-κT` 和 `+τB`

### 应试解题技巧

- 螺旋线 `(a cos s, a sin s, bs)` 对弧长参数，`κ = a`，`τ = b`（当 `a² + b² = 1`）
- 记忆口诀：T 转 N，N 转回 T 并朝 B，B 转回 N

## 17 可展曲面

### 核心定义定理

**可展曲面**是高斯曲率恒为零的直纹面。可展曲面可以展开为平面而不改变度量。

可展曲面包含三类：柱面、锥面、切线曲面（空间曲线的切线曲面）。

### 核心公式

- 可展曲面 ⇔ `K ≡ 0`
- 可展曲面 ⇔ 与平面局部等距

### 标准化分步解题流程

1. 计算 `E, F, G` 和 `L, M, N`
2. 计算 `K = (LN - M²)/(EG - F²)`
3. 验证 `K = 0`

### 考试高频陷阱

- 直纹面不一定可展（单叶双曲面是直纹面但不可展）
- `K = 0` 还需要曲面是直纹面才称为可展曲面

### 应试解题技巧

- 圆柱面、锥面是典型的可展曲面
- `LN - M² = 0` 说明高斯曲率为零

## 18 等距对应

### 核心定义定理

两个曲面间的**等距对应**（等距变换）保持曲面上曲线的长度。**局部等距对应** ⇔ 存在参数化使第一基本形式相同。

等距对应保持高斯曲率不变（高斯绝妙定理）。

### 核心公式

- 等距 ⇔ 在适当的参数化下 `E₁ = E₂, F₁ = F₂, G₁ = G₂`
- 等距 ⇒ `K₁ = K₂`（但反之不成立）

### 标准化分步解题流程

1. 计算两个曲面的第一基本形式系数
2. 比较是否能在某种参数化下得到相同的 `E, F, G`
3. 得出结论

### 考试高频陷阱

- 等距对应不保持第二基本形式（弯曲改变但度量不变）
- 全局等距比局部等距要求更严格

### 应试解题技巧

- 平面与圆柱面局部等距：两者均可用 `du² + dv²` 表示
- 实际例子：将纸张卷成圆柱是等距变换

## 19 Gauss-Bonnet定理

### 核心定义定理

Gauss-Bonnet 定理是微分几何最深刻的定理之一，它将曲面的曲率与拓扑联系起来：

```
∬_D K dA + ∫_{∂D} κ_g ds + Σ (π - 内角) = 2π χ(D)
```

其中 `χ(D)` 是区域 `D` 的 Euler 示性数。

### 核心公式

- 球面三角形（三条大圆弧围成）：`S = R²(α + β + γ - π)`
- 球面 Gauss 曲率：`K = 1/R²`（常值）

### 标准化分步解题流程

1. 确定区域 `D` 和边界
2. 计算各分量：`∬K dA`、`∫κ_g ds`、转角项
3. 代入 Gauss-Bonnet 公式求解未知量

### 考试高频陷阱

- 外角 = `π - 内角`，不要混淆内外角
- 球面三角形边是大圆弧（测地线），测地曲率为零

### 应试解题技巧

- 球面三角形面积公式 `S = R²(α+β+γ-π)` 是高频考点
- 球面正三角形 `α=β=γ=π/2` 占球面 `1/8` 面积
- **全等三角剖分的 Gauss-Bonnet 相容性**：当曲面被剖分为若干全等的球面三角形时，Gauss-Bonnet 定理对每个三角形给出 $K\cdot S_i+$边界项 $=\pi(\alpha_i+\beta_i+\gamma_i-\pi)$。由于全等，所有 $S_i$ 与角度均相同，整体积分退化为代数计数：若剖分中共有 $f$ 个面、$e$ 条边、$v$ 个顶点，且每个面有 $k$ 条边，则 $kf=2e$。结合在顶点处的总角度 $2\pi v=\sum(\alpha+\beta+\gamma)\cdot f/k$，可反解出剖分所需的全等三角形的角度大小，进而判定剖分是否可能存在于给定曲率的曲面上。
- **外切多边形相容性的曲率约束**：若一个凸多边形能"外切"于某曲面（即多边形的每个顶点都是曲面上的点，且多边形在曲面上的像由测地线段组成），则多边形内角和 $\sum\alpha_i$ 与 Gauss-Bonnet 定理对曲面区域的要求必须相容。关键在于：多边形沿边界测地线段时 $\kappa_g=0$，边界积分仅在外角处非零；若多边形依顺时针方向外切，外角总和为 $2\pi-\sum\alpha_i$。由此得出相容性必要条件 $\iint_D K\,dA=2\pi-\sum\alpha_i$，可用于排除不可能的外切多边形。

## 20 极小曲面判定

### 核心定义定理

**极小曲面**是平均曲率恒为零 `H ≡ 0` 的曲面。物理上对应"肥皂膜"的形状。

### 核心公式

| 条件 | 表达 |
|------|------|
| `H = 0` | `(EN - 2FM + GL) / [2(EG - F²)] = 0` |
| 等价条件 | `LG - 2MF + NE = 0` |

### 标准化分步解题流程

1. 计算 `E, F, G, L, M, N`
2. 代入 `LG - 2MF + NE` 化简
3. 验证结果为零

### 考试高频陷阱

- 仅用一个点验证不够，需要在整个曲面上 `H ≡ 0`
- `LG - 2MF + NE = 0` 中注意 `M` 和 `F` 的系数是 **-2**

### 应试解题技巧

- 优先验证 `LG - 2MF + NE = 0`，避免复杂的除法运算
- 悬链面和螺旋面是经典的极小曲面
- **约束优化与四边形面积问题**：四边形面积 $S=\frac{1}{2}d_1d_2\sin\theta$（$d_1,d_2$ 为对角线长度，$\theta$ 为对角线夹角）是连接微分几何与约束优化的桥梁。当四边形参数（边长、角度、对角线）受到约束时，面积的最大化等价于求解一个含三角函数的约束极值问题。常用技巧：固定四边形两条对角线的长度，转角 $\theta$ 使 $\sin\theta$ 在 $\theta=\pi/2$ 处最大——即对角线正交时面积最大（在边长约束下不一定总能正交，需引入 Lagrange 乘子）。
- **变分原理的几何直观**：极小曲面问题本质上是面积泛函 $A[\mathbf{r}]=\iint\sqrt{EG-F^2}\,du\,dv$ 的变分 $\delta A=0$。四边形面积最大化问题对应的"约束面积变分"可以看作在给定边界条件下的离散极小曲面。解法框架——先将连续 Euler-Lagrange 方程离散化为对角线上的代数约束，然后使用数值或解析方法直接求解最优角度。
- **对角线夹角的正交化判据**：在四边形面积优化中，若存在额外约束（如各边长已知），使用 Brahmagupta 公式 $S=\sqrt{(s-a)(s-b)(s-c)(s-d)}$（仅对圆内接四边形严格成立）可快速得到参考面积。对于一般四边形，使用 Bretschneider 公式 $S=\sqrt{(s-a)(s-b)(s-c)(s-d)-abcd\cos^2\frac{A+C}{2}}$，当对角线正交时存在进一步简化，可作为约束优化中的必要最优性条件。

### 竞赛拓展：平面点集的直线覆盖与 Erdős–de Bruijn 型定理

**核心内容**：Erdős–de Bruijn 定理断言，平面上 $n$ 个点若不全共线，则至少需要 $n$ 条直线才能完全覆盖它们。这一定理在组合几何中具有奠基地位，其本质是对点-线关联关系的极值刻画。

**定理**：设 $P$ 为平面上不全共线的有限点集，$|P|=n$。若一族直线 $\mathcal{L}$ 覆盖了 $P$ 中所有点（每条直线至少含 $P$ 中两点），则 $|\mathcal{L}|\ge n$，且等号成立当且仅当 $P$ 构成一个射影平面的正则构型（近正多边形顶点加对角线）。

**与微分几何的关联**：考虑平面曲线 $\mathbf{r}(t)$ 的离散采样点集 $P=\{\mathbf{r}(t_i):i=1,\ldots,n\}$。Erdős–de Bruijn 型下界给出了描述该曲线切触所需的"最小直线族"规模——这在离散微分几何的曲率估计和曲线重建中有直接应用。当采样点分布在一条光滑曲线上时，过每对相邻采样点的直线提供了曲线段的线性逼近；定理保证这些逼近直线的数量不小于点数，这与曲线的离散曲率估计中对"最短描述"的需求一致。

**考法提示**：给定点集和部分覆盖直线，求证存在未被覆盖的点或补全覆盖所需的最小直线数。常用方法是反证法加双计数——假设覆盖直线少于 $n$ 条，对每条直线上的点数求和，利用每条直线至少覆盖 2 点、且 $n$ 个点不全共线构造矛盾。

**易错点**：定理要求"不全共线"的前提不可忽略——若所有点共线，1 条直线即可覆盖。此外，等号成立的充要条件涉及射影平面的有限构型（如"近正多边形"），单独验证等号条件时容易用欧氏直觉替代射影几何推理。

**应试技巧**：
- 双计数：令 $\ell_i$ 为第 $i$ 条覆盖直线上的点数，则 $\sum\ell_i\ge n+$ 关联总数；结合每条直线至少含 2 点即得 $|\mathcal{L}|\le\sum(\ell_i-1)=\sum\ell_i-|\mathcal{L}|$
- 反证法路径：假设 $|\mathcal{L}|<n$ → 构造每条直线的"代表点"集合 → 鸽巢原理推出矛盾
- 最小直线族的显式构造范例：正 $n$ 边形顶点及所有对角线（当 $n$ 为素数时刚好 $n$ 条直线）

### 竞赛拓展：直角三角形中的张角拆分与线段比值

**核心内容**：直角三角形中从直角顶点向斜边引出的线段，将直角张角拆分为两个子角。子角的正切或余切与斜边上的两段截距之间存在精确的比值关系，在几何定位与三角函数求值中高频出现。

**设 $\triangle ABC$ 中 $\angle C=90^\circ$，$CD\perp AB$ 于 $D$**：
- $\tan\angle ACD=\frac{AD}{CD}$，$\tan\angle BCD=\frac{BD}{CD}$
- $CD^2=AD\cdot BD$（射影定理）
- $\frac{AD}{BD}=\frac{AC^2}{BC^2}=\frac{\tan^2 B}{\tan^2 A}$

**与微分几何的关联**：平面曲线的密切圆与切线的几何关系中，当曲线上某点的密切圆与该点处的切线及法线构成直角三角形时，张角拆分直接给出子弧的曲率分解。特别地，对于参数化曲线 $\mathbf{r}(t)$，$\mathbf{r}(t_0)$ 处的曲率圆与切线和主法线围成直角三角形，曲率圆半径 $R=1/\kappa$ 类似于上述直角三角形中的"斜边"，而沿切线方向和法向的投影给出了 $\kappa_n$ 和 $\kappa_g$ 的分离。

**考法提示**：已知直角三角形的某两条边长或某个角度，求从直角顶点出发的某条线段将直角分成两部分的比值。核心是应用三角函数恒等式和射影定理，将长度比转化为角度函数的比。

**易错点**：混淆斜边上的垂足 $D$ 与非直角的角平分线与斜边的交点——前者满足 $CD\perp AB$ 且 $CD^2=AD\cdot BD$；后者满足 $\frac{AD}{DB}=\frac{AC}{BC}$。两者截得的线段比完全不同，不可混用。

**应试技巧**：
- 射影定理三合一：$AC^2=AD\cdot AB$，$BC^2=BD\cdot AB$，$CD^2=AD\cdot BD$，可快速交叉验算
- 角度拆分联立方程：若题目给 $\angle ACD=\alpha$，$\angle BCD=\beta$，总有 $\alpha+\beta=90^\circ$
- 比例转换统一量纲：所有线段比用同一条斜边 $AB$ 归一化可消去多余参数

### 竞赛拓展：共线构型中的角度倍数关系与解计数

**核心内容**：当平面上若干点共线时，以这些点为顶点的角度之间存在整数倍数关系。典型问题形式为：点 $A,B,C$ 共线，另一点 $P$ 不在该直线上，已知 $\angle APB=k\angle BPC$（$k$ 为正整数），求满足条件的 $P$ 的位置和解的个数。

**与微分几何的关联**：该构型对应 Apollonius 圆的退化形式——给定共线三点 $A,B,C$ 和倍角关系，满足 $\angle APB/\angle BPC=k$ 的点 $P$ 的轨迹是一族圆弧（等角轨线）。从微分几何视角看，这些圆弧的曲率与 $k$ 之间的关系给出了从离散角度约束到连续曲线曲率的对应：圆弧半径 $R$ 满足 $1/R\propto\sin(k\theta)/d(A,C)$，其中 $d(A,C)$ 是共线两端的距离。

**考法提示**：已知共线的三点 $A,B,C$ 及正整数 $k$，求满足 $\angle APB=k\angle BPC$ 的点 $P$ 的轨迹或解的个数。使用角平分线定理的推广并结合正弦定理在 $\triangle APB$ 和 $\triangle BPC$ 中建立比例方程。

**易错点**：
- 当 $k=1$ 时退化为 Apollonius 等角轨线，$P$ 在 $AB$ 和 $BC$ 的角平分线交点上——但有 $2$ 个解（$P$ 在直线两侧各一个）
- 当 $k\ge2$ 时，解的数量不再是简单的 $2$——方程变为高次多项式，解的个数依赖于 $k$、点距比 $AB:BC$、以及是否允许 $P$ 在直线 $ABC$ 的异侧
- 不能机械套用角平分线定理——该定理仅对 $k=1$ 成立

**应试技巧**：
- 建立坐标系：以 $A$ 为原点，$ABC$ 为 $x$ 轴，令 $B(a,0)$，$C(b,0)$，$P(x,y)$
- 使用正切和差公式：$\tan\theta=y/x$，$\angle APB$ 由向量 $\overrightarrow{PA}$ 与 $\overrightarrow{PB}$ 的正切差表示
- 最终方程化为 $P$ 坐标的代数方程，通过代入判别式判断解的数量
- 对称性利用：若 $AB=BC$，构型在反射下对称，解也成对出现

### 竞赛拓展：三圆公共点条件与过定点切定直线的圆

**核心内容**：给定平面上两条直线 $\ell_1,\ell_2$ 和一定点 $P$，求过 $P$ 且同时与 $\ell_1,\ell_2$ 相切的圆。这类问题涉及圆族公切条件、根轴与根心（等幂心），以及 Apollonius 问题的一个特例。

**三圆共点条件**：三个圆 $C_1,C_2,C_3$ 若两两相交，它们有公共交点当且仅当三个根轴共点（交于根心）。根轴方程：对于圆 $C_1:x^2+y^2+D_1x+E_1y+F_1=0$ 和 $C_2:x^2+y^2+D_2x+E_2y+F_2=0$，根轴为 $(D_1-D_2)x+(E_1-E_2)y+(F_1-F_2)=0$。

**过定点切定直线的圆的构造**：令所求圆的方程为 $(x-a)^2+(y-b)^2=r^2$。过定点 $P(x_0,y_0)$ 给出 $(x_0-a)^2+(y_0-b)^2=r^2$；与直线 $Ax+By+C=0$ 相切给出 $\frac{|Aa+Bb+C|}{\sqrt{A^2+B^2}}=r$。对于两条切线，共两个此类距离约束，连同过定点约束构成三元（$a,b,r$）二次方程组。

**与微分几何的关联**：从欧氏平面几何到微分几何的过渡——切圆问题中的"过定点且切于定直线"等价于求解密切圆与曲线的切触阶。在曲线 $\mathbf{r}(t)$ 上，密切圆在切点处同时满足"过定点"和"切于切线"两个条件（切触阶为 $2$）。更一般地，若曲线与圆有三阶切触（超密切圆），则在非顶点处唯一确定且对应曲线的局部"最佳圆逼近"。

**考法提示**：给定两直线和一个定点，求过定点且与两直线均相切的圆的数量及方程。通常分两种情况讨论——定点在两条直线的同侧（共有 $2$ 个解）还是异侧（可能无解或 $1$ 个解）。使用距离约束导出关于圆心坐标的二次方程，判别式符号决定解的数量。

**易错点**：
- "圆与直线相切"的代数表达中绝对值不可省略——圆心可能在直线的任意一侧
- 两切线加一定点可能定出 $2$ 个不同的圆（对称位置），也可能无解（定点在两直线的角平分线上但不在二者的等距线上）
- 混淆 Apollonius 问题的 LLL（三直线）与 PLL（定点+两直线）版本

**应试技巧**：
- 先求两直线的角平分线（共两条），圆心必然落在这两条角平分线之一上
- 在每条角平分线上参数化圆心位置，用定点距离约束反解圆心坐标
- 使用几何验证：任意位置中的定点到两切线的距离与圆心半径的一致性检查

### 竞赛拓展：直角三角形外接圆中的切线、弧中点与角度闭合

**核心内容**：直角三角形外接圆（Thales 圆）上的若干特殊点——直角顶点（位于圆上）、斜边中点（即圆心）、弧中点、及过这些点的切线——之间满足角度闭合关系，形成三弦定理（Butterfly 定理）的一个特例。

**基本构型**：$\triangle ABC$ 中 $\angle C=90^\circ$，外接圆 $O$（以 $AB$ 为直径）。设 $M$ 为弧 $\widehat{AB}$（不含 $C$ 的半圆弧）的中点，则 $CM$ 平分 $\angle ACB=90^\circ$（即 $CM$ 为直角平分线）。过 $C$ 的切线 $t_C$ 满足 $t_C\perp OC$，其中 $OC$ 是半径。

**角度闭合关系**：$A,B,C$ 在外接圆上，过 $C$ 的切线与弦 $CA$ 的夹角等于弦 $CB$ 所对的圆周角 $\angle CAB$（弦切角定理）。此即 $\angle$（切线 $t_C$, 弦 $CA$）$=\angle CBA$。同理 $\angle$（$t_C$, 弦 $CB$）$=\angle CAB$。由此 $\angle CAB+\angle CBA=90^\circ=\angle ACB$，验证角度闭合。

**与微分几何的关联**：在曲面上的测地三角形中，类似的"切线角 = 对侧圆周角"关系由 Gauss-Bonnet 定理推广——在常曲率曲面上，测地三角形的内角和与切向角偏离之间存在曲率加权的修正项。特别地，球面三角形的外切圆锥线与平面直角三角形外接圆的对应关系，在球面几何课程中是重要考点。

**考法提示**：已知直角三角形，作其外接圆，引入弧中点或切点，求证某两个角相等或互补。核心工具是弦切角定理（Alternate Segment Theorem）和 Thales 定理的协同使用。

**易错点**：
- 弦切角定理的"弦"指的是从切点出发的弦，且弦切角等于该弦所对的另一侧的圆周角——注意"同侧/异侧"的选择
- 弧中点的"弧"需明确是优弧还是劣弧——直角三角形的非直角顶点将外接圆分为两个弧段
- 角度闭合的验证不能仅依赖量角器直觉，必须用弦切角定理进行严格推导

**应试技巧**：
- 画标准图时斜边水平、直角在上方最便于标记角度
- 三弦定理（定点、切点、弧中点共线）的几何验证：过弧中点的弦在两切线段上截等长
- 坐标法也可行——以圆心为原点，AB 为直径，$A(-R,0)$，$B(R,0)$，$C(R\cos\theta,R\sin\theta)$

### 竞赛拓展：极线包络与垂心配置

**核心内容**：给定圆锥曲线 $\Gamma$（通常是椭圆、抛物线或双曲线），点 $P$ 关于 $\Gamma$ 的**极线**是与 $P$ 互为极-极关系的直线。当 $P$ 沿某轨迹移动时，其极线族的**包络**构成另一条曲线——对偶曲线。垂心配置则研究三角形中三条高线、九点圆与极线包络之间的深层关联。

**极线方程**：对于圆锥曲线 $Ax^2+Bxy+Cy^2+Dx+Ey+F=0$，点 $P(x_0,y_0)$ 的极线方程为 $Ax_0x+\frac{1}{2}B(x_0y+xy_0)+Cy_0y+\frac{1}{2}D(x+x_0)+\frac{1}{2}E(y+y_0)+F=0$。特别地，圆 $x^2+y^2=R^2$ 上点 $(x_0,y_0)$ 的极线为 $x_0x+y_0y=R^2$（即该点处的切线）。

**垂心与极线的关联**：$\triangle ABC$ 的垂心 $H$ 关于外接圆的极线恰好是垂足三角形的外接圆（九点圆）的某条特殊线。具体地，$H$ 的极线是外接圆关于 $\triangle ABC$ 的"极轴"——它与三条边所在直线交出 Simson 线相关的点。

**与微分几何的关联**：极线包络本质上是 Legendre 变换（对偶变换）在平面曲线上的离散体现。在微分几何中，曲线的渐屈线（evolute）就是其法线族的包络，而极线族可视为一种广义法线族。对于光滑闭凸曲线，其极线包络给出对偶曲线，且满足对偶的曲率互反关系（与椭圆-双曲线的对偶类似）。

**考法提示**：给定三角形及其外接圆或九点圆，求证某三点共线（如垂心、外心与某特殊点）或某线为某点的极线。核心工具是极线的代数定义和极-极对偶原理（若 $P$ 在 $Q$ 的极线上，则 $Q$ 在 $P$ 的极线上）。

**易错点**：
- 极线的定义依赖于所选的圆锥曲线——换个曲线，同一点的极线完全不同
- 垂心只在锐角三角形中才严格位于形内——钝角三角形中垂心在形外，极线关系可能需要带符号处理
- 包络线的参数方程不能直接对极线族方程求关于参数的偏导，需要先转换为隐式后再用包络定理

**应试技巧**：
- 对称性简化：在等腰或等边三角形中，垂线和极线具有自然的轴对称性
- 坐标法的优势——以外接圆圆心为原点，$A(R\cos\alpha,R\sin\alpha)$ 等，极线方程自动退化到最简形式
- 极-极对偶原理的链式传递：$P\rightarrow Q\rightarrow R$ 的极线链在研究三点共线问题时尤为高效

### 解题工具选择

1. **向量法**：曲线问题优先使用向量叉积和点积
2. **参数化**：曲面问题先完成参数化，再计算偏导

4. **对称性**：利用曲面对称性减少计算量

### 结果核验思路

1. **量纲检查**：曲率量纲为 `1/长度`，弧长为 `长度`，面积为 `长度²`
2. **特殊值验证**：取退化情形的已知结果对比
3. **符号一致性**：`K` 的符号应与曲面形状定性一致
4. **经典公式验证**：螺旋线 `κ = a/(a²+b²)`，`τ = b/(a²+b²)`

## 模块速查：平面点集的直线覆盖与 Erdős–de Bruijn 型定理
- 检索词：覆盖 cover covering 最大 maximum largest greatest circle circles disk 直线 line lines 点集 points plane configuration 构造 construction construct 上界 upper bound
- 核心内容：点集 S 同时满足"不能被给定数目的直线整体覆盖、也不存在经过全部点的圆"与"删去任一点后剩余点集可被同样数目的直线覆盖"两个条件，求最大点数。典型构造：取一般位置直线族（无平行、无三线共点），令 S 为全部两两交点；删去某一交点后，剩余交点恰好落在除去确定该交点的那两条直线之外的所有直线上，天然满足删除覆盖条件；"无圆经过全部点"需另行验证。上界来自 Erdős–de Bruijn 型定理：满足此类覆盖条件的点集大小受直线数目的二次量级限制，且构造中的交点总数恰达该上界。
- 解题路线：对称的"整体不可覆盖/删一点可覆盖"条件强烈暗示交点集构造；上界论证用对偶视角（点与直线的关联计数），构造与上界一致时答案即为交点总数。
- 易错点：直线族须为一般位置（平行与三线共点会改变交点计数与覆盖结构）；"删去一点后仍用同数目直线"要求每个交点恰好由两条直线确定（其余直线仍保留）；共圆约束是额外条件，构造后须显式排除。

## 模块速查：直角三角形中张角拆分与线段比值
- 检索词：三角形 triangle triangles 张角 angle subtend 比值 ratio
- 核心内容：直角三角形中，在一条直角边上取两个分点，使斜边端点对分点所张的角满足给定的拆分（两个已知小角），求两条被截线段之比。解题链：按张角所在位置把图形分解为两个小三角形，分别在每个三角形中用正弦定理把目标线段表为该三角形中相邻直角边（或斜边）与对应角正弦之比；再利用直角三角形的边角关系（锐角互余、正余弦互换）统一到同一参考边长；最后以倍角公式化简正弦之比，比值与三角形尺寸无关，恒为常数。
- 解题路线："角度拆分 + 求线段比"是高发题型——先画准张角的两条射线，再逐三角形用正弦定理，最后三角恒等化简；结果与边长无关是这类题目的典型特征。
- 易错点：分点的先后顺序决定张角的构图，标错即全盘皆错；正弦定理中"对角"取错（对边与对角必须一一对应）；倍角公式展开时漏系数；所求比值的分子分母在题面中的顺序须逐字核对。

## 模块速查：凸多边形面积平分线及其落边分布
- 检索词：顶点 vertex vertices 最小 minimum smallest least minimal convex 面积 area 多边形 polygon 构造 construction construct 上界 upper bound 分布 distribution 平分线 bisector
- 核心内容：凸多边形内自每个顶点发出的面积平分线段与对侧边界相交。全体落点的分布规律由连续性划分论证控制：面积平分线把多边形区域连续扫过，各顶点对应的落边按边界顺序聚成至多常数个连续段，因此所有落点至多落在与边数无关的常数条边上。最小值问题归结为"该常数上界 + 对任意边数均存在恰好如此分布的构造"，两者吻合即得答案。
- 解题路线：见到"与 n 相关的量求最小可能值"先判断是否与 n 无关（连续/介值论证），再补构造；构造中需逐个核对题设约束（落点不得与顶点重合等）。
- 易错点：把面积平分线与中线混淆（面积平分线不必过对边中点）；划分论证的"连续段"计数依赖边界顺序，漏掉端点重合情形会多算或少算落边数。
- 分步收尾：顶点面积平分线的落点随顶点连续扫动 ⇒ 全部落点至多聚在 3 条边上；最小值与 n 无关恒为 3：n=3 即中线情形，n≥4 用近退化构造达成恰 3。答案是常数 3，不是 n 的函数。

## 模块速查：全等三角剖分与外切多边形的相容性
- 检索词：顶点 vertex vertices 最小 minimum smallest least minimal 三角形 triangle triangles circle circles disk 切线 tangent tangency convex 四边形 quadrilateral 多边形 polygon 对称 symmetric symmetry
- 核心内容：凸多边形被互不相交的对角线剖分为全等三角形时，剖分结构（三角形个数、各顶点处汇集的角数）由边数固定，全等性把全部内角强制为同一组角的整数倍分配。若同时要求多边形外切于圆（有内切圆），需满足对边和相等或角平分线共点。两者相容仅发生在边数最小的情形：此时全等剖分强制的对称性（筝形）叠加切线条件后迫使四边相等，成为恒有内切圆的特殊四边形；边数更多时可用角度总量或对称性破坏论证逐类排除。
- 解题路线：先由剖分结构列角度分配方程，再与外切条件联立；"求所有可行边数"的题用"最小情形构造可行 + 其余情形排除"。
- 易错点：内接（有外接圆）与外切（有内切圆）两组条件不同，切勿混用；全等三角形在不同顶点处汇集的角数不同，需按顶点逐一核对内角和。

## 模块速查：共线构型中的角度倍数关系与解计数
- 检索词：最大 maximum largest greatest 计数 count counting number ways 张角 angle subtend 直线 line lines 区间 interval
- 核心内容：线段所在直线上取动点使两条张角满足倍数关系（一角恰为另一角的一半），本质是"射线三等分张角"的几何图景。用正弦定理或相似把每个比例关系化为动点位置（到交点距离）的方程；固定直线的倾角后，每个比例关系在每条射线（点的两个方向）上至多一个解。最大解数在所有解同时存在的相容区间内取得，相容条件由线段两端到交点的距离之比与直线倾角共同决定。
- 解题路线：解计数标准流程——每射线每关系至多一解 → 枚举关系与方向 → 检查同时成立的范围条件；答"最大值"需给出达到该值的构型条件而非仅计数。
- 易错点：漏掉动点在另一条射线上的解；"较大角是较小角的两倍"与相反说法是两种不同情形；端点距离之比超出相容区间时解的个数骤减。
- 分步收尾：倍角关系逐射线至多一解：2 种关系×2 个方向 ⇒ 上限 4；两端距离比落在 (1/2,2) 型相容区间且倾角合适时 4 解同时存在 ⇒ 最大解数=4，并给出相容条件。

## 模块速查：凸多面体面可见性与法向量分离
- 检索词：最小 minimum smallest least minimal convex 多面体 polyhedron faces visible 构造 construction construct 法向量 normal vector 可见 observer 向量 vectors
- 核心内容：从外部观察点看凸多面体，某面可见当且仅当该面外法向量与视线方向的点积为正。要求每个面都存在一个点使其余各面全可见而仅隐藏该面，等价于每个面的法向量都可用过原点的平面与其他全部法向量分离。三维中该性质只对单纯形配置（四面体的对偶结构）成立，故满足条件的面数被限制在最小值；构造上对四面体每个面取"贴近该面、位于其余三面外侧"的观察点即可逐面验证。
- 解题路线：把几何可见性翻译为法向量的线性分离问题，再调用凸锥与分离类结论（如 Carathéodory 定理）；先证上界（面数不能更大）再给构造（达到上界）。
- 易错点：只验证"存在某点可同时看到大部分面"而遗漏"每个面都要被单独隐藏"的逐面条件；观察点需严格位于该面外侧半空间内。
- 分步收尾：逐面单独隐藏 ⇔ 每个法向量可与其余全部法向量被过原点超平面分离 ⇔ 单纯形法向配置 ⇒ 面数最小=4（四面体逐面取贴面外侧观察点验证）。

## 模块速查：三圆公共点条件与过定点切定直线的圆
- 检索词：circle circles disk 直线 line lines root roots 唯一 unique uniquely uniqueness
- 核心内容：参数化圆族的公共点问题。三个圆恰有两个公共点等价于三圆两两相交于同一对点（共轴），可用根轴共点或公共弦重合判定。单个圆"过某定点且与定圆在定切点相切"时，圆心位于过切点的法线上、半径由定点位置唯一确定，因而整族圆的圆心、半径都是参数的显式函数；把共轴条件写成代数方程解出参数的全部取值即可。
- 解题路线：几何对象参数化后转为代数（写圆心半径公式 + 列共轴判别式）；"求所有参数"型题目，解的个数与参数的特殊几何位置（如内分比例与对称退化）一一对应，需逐一核对。
- 易错点：把"恰有两个公共点"与"三圆共点"混淆；相切（二重交点）情形的计数口径须与题设一致；切点固定时圆心可解的前提是切线与法线方向明确。
- 分步收尾：单位外接圆坐标化写三圆方程，共轴判别式对参数数值扫描（如 k∈[0.1,3]）定位候选（k=1/2 与 k=1 型），再补几何论证（中点构型/旁心构型）。答案常是两个分数值，都要报。

## 模块速查：直角三角形外接圆中的切线、弧中点与角度闭合
- 检索词：顶点 vertex vertices 三角形 triangle triangles 圆周 circle circumference circles disk 切线 tangent tangency 外接圆 circumcircle circumscribed arc midpoint
- 核心内容：直角三角形外接圆以斜边为直径（泰勒斯定理），是此类配置的起点。题目链条为：顶点处切线交对边延长线 → 取劣弧中点 → 连线与圆再交 → 新交点处切线交另一直角边 → 求角度。链中反复使用三个工具：弧中点性质（与端点等距、对应角平分关系）、切线—弦角定理、直径所张圆周角为直角；角度等式链闭合后结论常与三角形具体形状无关，恒为直角。
- 解题路线：解析化（外心置原点、斜边落在坐标轴）可把整条链条化为直线与圆的交点计算，角度由斜率或向量点积读出；"求角度"题优先寻找隐藏的直角与等腰关系。
- 易错点：切线与边的交点可能落在延长线上，影响角的方向（需按有向角处理）；劣弧与优弧中点对应不同分支，取错弧段会得到互补角；每个切点处的切线—弦角须对应对应弦。

## 模块速查：极线包络与垂心配置
- 检索词：顶点 vertex vertices 三角形 triangle triangles circle circles disk 切线 tangent tangency 外接圆 circumcircle circumscribed 垂心 orthocenter 极线 polar line pole 轨迹 locus
- 核心内容：以三角形顶点为圆心、到垂心的距离为半径的三个圆；对圆外动点取三个圆的极线，三线围成三角形，研究其外接圆与动点的位置关系。核心退化性质：点在圆上时其极线恰为该点处的切线。由垂心到三个顶点距离恰为相应圆半径（垂心同时在三个圆上），特殊位置处三条极线即三条切线，围成三角形，且该三角形的外接圆恰通过特殊位置点——据此可判定轨迹形态。
- 解题路线：极线题先找"点在圆上 ⟹ 极线为切线"的退化情形再谈一般位置；轨迹题结论形态（整圆、直线族或退化单点）要由特殊点与一般点共同确定。
- 易错点：漏用极与配极的对偶性；垂心在三个圆上这一事实需先由定义验证（半径正是到垂心距离）；三切线围成三角形外接圆过该点的共圆性需用四点共圆或交比验证。
- 分步收尾：先试特殊点 Y=垂心 M：三极线为切线且所成三角形以 M 为垂心、外接圆过 M ⇒ M 在轨迹上；随机数值扫描确认无其他点 ⇒ 轨迹为单点 {M}（垂心），不是曲线。

## 模块速查：四边形面积、对角线夹角与约束优化
- 检索词：最大 maximum largest greatest 三角形 triangle triangles convex 面积 area 夹角 angle 四边形 quadrilateral 上界 upper bound 对称 symmetric symmetry
- 核心内容：凸四边形面积可沿对角线分解为两个三角形面积之和，亦可写成两对角线长之积乘以夹角正弦的一半——面积由两对角线与其夹角的正弦表示。在周长约束下求最大面积的标准流程：把面积表为自由变量（对角线夹角与边长分解）的函数 → 用周长与对角线约束放缩出上界 → 令各放缩同时取等号得到最优构型，通常为关于对角线对称的筝形配置。
- 解题路线：面积公式 S=½·d₁d₂·sinθ 与三角形面积分解是最常用入口；"周长固定求最大面积"几乎总收敛到对称极值，可先猜对称构型再验证；等号条件必须逐条写清。
- 易错点：夹角互补时正弦值相同，枚举极值需覆盖钝角情形；周长约束下边长自由度不止一个，消元时遗漏凸性（任一边小于其余三边之和）与凸四边形条件。
