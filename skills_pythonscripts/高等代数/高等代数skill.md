# 高等代数解题技能手册

## 领域边界与路由约定

- 适用范围：多项式、矩阵、行列式、线性空间、二次型、特征值、代数数、$ℓ_2$ 状态和 max-plus 结构。
- 不接管：群/环/域/Galois 的结构题转抽象代数；实变量极限、收敛和微分不等式转数学分析。
- 验证契约：保留系数域、维数、重数、可逆变换和退化情形；矩阵/多项式结果必须回代原对象。

## 前言

本手册基于 20 道典型习题（计算 14 道 + 证明 6 道，难度比例 2:6:2），系统梳理高等代数的核心解题技能。

## 一、多项式理论

### 核心概念

- **多项式环** $F[x]$：系数取自数域 $F$ 的一元多项式全体
- **整除性**：$f(x) \mid g(x)$ $\iff$ 存在 $h(x)$ 使 $g = f \cdot h$
- **最大公因式**：$\gcd(f,g)$，辗转相除法求得
- **互素**：$\gcd(f,g)=1$，即无非平凡公因式
- **不可约多项式**：次数 $\ge 1$，不能分解为两个次数更低的多项式之积

### 常用公式与定理

| 名称 | 内容 |
|---|---|
| 带余除法 | $f(x) = q(x)g(x) + r(x)$，$\deg r < \deg g$ |
| Bezout定理 | $(f,g)=1 \iff \exists u,v: uf+vg=1$ |
| 因式定理 | $x-a \mid f(x) \iff f(a)=0$ |

### 标准解题步骤

**题型A：多项式除法**
1. 用长除法或综合除法
2. 检查余式次数 < 除式次数
3. 利用余数定理 $r=f(a)$ 快速验证

**题型B：求最大公因式**
1. 执行Euclid辗转相除法
2. 最后一个非零余式归一化即为最大公因式

**题型C：互素证明**
1. 假定存在公因式 $d$（次数 $\ge 1$）
2. 利用整除关系和互素条件推导矛盾

### 常见陷阱

- 忘记检查**余式次数**必须严格小于除式次数
- 最大公因式必须是**首一多项式**
- "不可约"依赖系数域：$x^2+1$ 在 $\mathbb{R}[x]$ 不可约，在 $\mathbb{C}[x]$ 可约

### 做题技巧

- 综合除法每次只操作系数，比长除法快3倍以上
- 求最大公因式时允许对中间余式乘以非零常数简化计算
- 证明互素常用套路：反证法 + 不可约多项式整除性质

### 应试解题技巧

- **幂和矩条件处理**：看到 $\sum P(a_i) = \text{const}$ 型条件时，先用拉格朗日插值或因式分解将其转化为多项式整除关系，再分类讨论。关键思路是构造 $Q(x) = \prod(x-a_i)$ 作为辅助多项式
- **多项式次数控制**：在函数方程问题中，先通过代入特殊值（$x=0, \pm1$ 等）缩小未知量的范围，再利用多项式次数有限性（$\deg f \le n$）将无穷维问题化为有限维待定系数问题
- **因式分解反证法**：若某个多项式的取值在所有整数点满足某种求和条件，利用 $g(x) = f(x+1) - f(x)$ 降低次数后迭代论证

### 考试高频陷阱

- 忘记检查**余式次数**必须严格小于除式次数
- 最大公因式必须是**首一多项式**
- "不可约"依赖系数域：$x^2+1$ 在 $\mathbb{R}[x]$ 不可约，在 $\mathbb{C}[x]$ 可约
- **重根与导数的关系**：$f$ 有重根 $\iff \gcd(f, f') \neq 1$；忘记求导数来判定重根是常见失分点
- **部分分式展开中重根的系数形式**：$F'/F$ 的部分分式中，$k$ 重根贡献 $\frac{k}{x-a}$ 而非 $\frac{1}{(x-a)^k}$，混淆这两种形式会导致实根个数判定错误

### 竞赛拓展：函数方程的多项式化方法

**概念**：许多函数方程（如 $f(x+y) = f(x) + f(y) + \text{多项式项}$）的解最终可化为多项式。核心策略是通过特殊值代入和差分消去非多项式部分。

**关键公式**：
- 前向差分：$\Delta f(x) = f(x+1) - f(x)$；$k$ 次差分消去 $k$ 次多项式
- 若 $f$ 满足 $\Delta^n f(x) \equiv 0$，则 $f$ 是次数 $< n$ 的多项式

**解题步骤**：
1. 代入 $x=y=0$ 等特殊值消去未知量
2. 对 $y$ 取特殊值（如 $y=1$）化为递推关系
3. 利用差分迭代降低次数，证明解为多项式
4. 待定系数法求解

**易错点**：仅在有理点验证不足以推出多项式恒等——必须配合连续性条件或多项式次数上界。若未证明函数是多项式就直接用插值，结论不完备。

### 竞赛拓展：对数微分与实根判定

**概念**：利用对数导数 $F'(x)/F(x)$ 的部分分式展开，将 $F$ 的实根个数与展开式各极点联系起来。

**核心原理**：
$$F(x) = c\prod_{i=1}^{k}(x-a_i)^{m_i} \prod_{j=1}^{l}((x-b_j)^2 + c_j^2)^{n_j}$$
$$\frac{F'(x)}{F(x)} = \sum_{i=1}^{k} \frac{m_i}{x-a_i} + \sum_{j=1}^{l} \frac{2n_j(x-b_j)}{(x-b_j)^2+c_j^2}$$

- 每个 $m$ 重实根对应 $\frac{m}{x-a}$ 项
- 计算 $\frac{F'}{F}$ 的符号变化次数可判定实根区间

**解题步骤**：
1. 计算 $F'(x)$ 和 $\gcd(F, F')$ 消去重因子
2. 对去重后的 $F$ 做部分分式展开 $F'/F$
3. 通过 Sturm 序列或符号分析判定实根个数

**易错点**：$F'/F$ 的部分分式展开中重根贡献 $\frac{m}{x-a}$ 形式（$m$ 为重数），而非 $\frac{1}{(x-a)^m}$。二阶导数符号用于区分重根与单根的局部行为。

### 竞赛拓展：多项式不变量与参数变换群

**概念**：给定参数变换群（如仿射变换 $x \mapsto ax+b$）作用在多项式上，寻找在该变换下不变的多项式系数组合。

**关键概念**：
- **判别式** $\Delta(f)$：$f$ 的根之差的平方乘积，在平移 $x \mapsto x+c$ 下不变，在缩放 $x \mapsto ax$ 下乘以 $a^{n(n-1)}$
- **结式** $\operatorname{Res}(f,g)$：$f$ 和 $g$ 有公根的充要条件
- **基本不变量组**的个数 $=$ 参数个数 $-$ 变换群的维数

**解题步骤**：
1. 确定变换群 $G$ 在系数空间上的作用
2. 计算 $G$ 作用下的轨道维数
3. 构造维数 = 系数个数 - 轨道维数 的基本不变量组
4. 验证不变量在 $G$ 作用下不变

**易错点**：不变量的个数是系数空间维数减去群的维数（而非轨道维数）；判别式 $a^{2n-2}\prod_{i<j}(r_i-r_j)^2$ 在 $x \mapsto \frac{ax+b}{cx+d}$ 下一般会变（仅在 Mobius 变换的不变理论中讨论）。

### 竞赛拓展：对称多项式方程组的消元与计数

**概念**：对于循环对称方程组 $\{f(x_1,\ldots,x_n)=0, f(x_2,\ldots,x_1)=0, \ldots\}$，利用对称性消元并借助 Bézout 定理计算解个数的上界。

**核心方法**：
- **初等对称多项式转换**：令 $s_1=\sum x_i$, $s_2=\sum_{i<j} x_i x_j$, ..., $s_n = \prod x_i$
- **Bézout 定理上界**：$n$ 个 $n$ 元多项式方程若均为 $d$ 次，则解个数 $\le d^n$（计重数）
- **Gröbner 基消元**：用计算机代数系统逐次消元得到单变量方程

**解题步骤**：
1. 识别方程组的对称性（循环对称 / 完全对称）
2. 转化为初等对称多项式方程组
3. 消元或利用 Newton 恒等式
4. 对消元后的单变量方程求解，回代得到全部解

**易错点**：对称性只在所有方程轮换后不变时才可使用；部分对称（如只有两个变量对称）不能化简为完全对称多项式；Bézout 上界是计重数的，实际不同解可能远少于上界。

### 竞赛拓展：多项式取值求和条件的恒等变形与分类反证

**概念**：给定多项式在一组点上的取值满足某些求和条件（如幂和矩条件 $\sum P(a_i)^k = S_k$），通过恒等变形、因式分解与分类讨论反证法，可以唯一确定多项式的形式或证明其不存在。

**关键公式与方法**：
- 幂和矩条件 $\sum_{i=1}^{n} P(a_i)^k$ 可通过 Newton 恒等式转化为初等对称多项式的关系
- 因式分解辅助函数：构造 $Q(x) = \prod_{i=1}^{n}(x - a_i)$，利用 $\sum \frac{P(a_i)}{Q'(a_i)}$ 形式的 Lagrange 插值恒等式
- 差分降次：若 $\sum_{i} P(a_i) = S$ 对所有满足某性质的集合 $\{a_i\}$ 成立，考虑 $g(x) = P(x+1) - P(x)$ 降低次数后迭代论证
- 模 $p$ 归约：在整数取值问题中，取合适的素数 $p$ 做模归约可排除大量不可能情形

**解题步骤**：
1. 将给定的求和条件改写为对称多项式形式，或利用 Newton 恒等式转换幂和为初等对称多项式
2. 构造辅助多项式（如 $Q(x) = \prod(x-a_i)$）并利用因式分解将求和条件转化为整除关系
3. 按多项式的次数、首项系数等参数分类，逐类分析可能性
4. 对每一类利用反证法：假设存在满足条件的多项式，推导矛盾（通常利用次数有限性或整系数约束）
5. 必要时使用模 $p$ 归约进一步限制系数取值

**易错点**：
- 求和条件 $\sum P(a_i)=0$ 与逐点条件 $P(a_i)=0$（对所有 $i$）不等价——前者不能直接推出后者
- 分类讨论时容易遗漏退化情形（常数多项式、零多项式等边界情况）
- 模 $p$ 归约后信息丢失（只保留了模 $p$ 的同余类），不能直接由模 $p$ 结论反推原方程的全部解

### 竞赛拓展：代数数、极小多项式与根式扩张

**核心概念**：
- **代数数**：若存在非零整系数多项式 $f(x) \in \mathbb{Z}[x]$ 使 $f(\alpha) = 0$，则称 $\alpha$ 为代数数。
- **极小多项式**：代数数 $\alpha$ 所满足的次数最低的首一整系数多项式 $m(x)$，它在 $\mathbb{Q}[x]$ 中不可约，且整除任何以 $\alpha$ 为根的多项式。
- **域扩张**：$\mathbb{Q}(\alpha) = \{a_0 + a_1\alpha + \cdots + a_{n-1}\alpha^{n-1} : a_i \in \mathbb{Q}\}$，其中 $n = \deg m$ 为扩张次数。$\{1, \alpha, \ldots, \alpha^{n-1}\}$ 构成 $\mathbb{Q}(\alpha)$ 作为 $\mathbb{Q}$-线性空间的一组基。

**降幂展开法（求极小多项式的标准流程）**：

以 $x = \sqrt[3]{a} + \sqrt[3]{b}$（其中 $a, b$ 为有理数）为例：

1. **确定基**：$\sqrt[3]{a}$ 的极小多项式为 $t^3 - a$，故 $\{1, \sqrt[3]{a}, \sqrt[3]{a}^2\}$ 是 $\mathbb{Q}(\sqrt[3]{a})$ 的基。若 $b$ 与 $a$ 不在同一次域中，则 $\mathbb{Q}(\sqrt[3]{a}, \sqrt[3]{b})$ 的基为 $\{\sqrt[3]{a}^i \sqrt[3]{b}^j : 0 \le i, j \le 2\}$（共 9 个基元素）。
2. **建立乘法表**：利用 $\sqrt[3]{a}^3 = a$、$\sqrt[3]{b}^3 = b$ 把任何高于二次的幂降回基内。例如 $\sqrt[3]{a}^2 \cdot \sqrt[3]{a} = a$。
3. **展开 $x$ 的各次幂**：逐次计算 $x, x^2, x^3, \ldots$，每次把结果在基下线性展开。由于基的维数有限（本例 9 维），$x$ 的某个幂必可由低次幂线性表出，从而得到 $x$ 满足的多项式方程。
4. **验证不可约性**：所得多项式次数若等于扩张次数 $[\mathbb{Q}(x):\mathbb{Q}]$，即为极小多项式。

**待定系数法（求 $\alpha$ 在扩域中的代数关系）**：

设需要在 $\mathbb{Q}(\alpha)$ 中求某量 $\beta$ 满足的最低次多项式：

1. 把 $\beta$ 在基 $\{1, \alpha, \ldots, \alpha^{n-1}\}$ 下展开，得到坐标表示。
2. 设待定多项式 $P(t) = c_0 + c_1 t + \cdots + c_k t^k$（$k$ 从小到大尝试）。
3. 把 $P(\beta)$ 也在同一基下展开，各坐标得到关于 $c_0, \ldots, c_k$ 的线性方程组。
4. 由基的**线性无关性**，$P(\beta) = 0$ $\iff$ 各坐标方程同时为零。解方程组得系数，并回代验证。
5. 验证 $k$ 确实是最小次数（即 $c_k \neq 0$ 的解存在，而 $k-1$ 次无非零解）。

**具体示例**：$x = \sqrt[3]{3} + \sqrt[3]{9}$

- 基：$\{1, \sqrt[3]{3}, \sqrt[3]{9}\}$（因为 $\sqrt[3]{9} = (\sqrt[3]{3})^2$，所以 $x \in \mathbb{Q}(\sqrt[3]{3})$，扩张次数为 3）。
- 乘法表：$\omega = \sqrt[3]{3}$，$\omega^3 = 3$，$\omega^4 = 3\omega$。
- $x = \omega + \omega^2$
- $x^2 = \omega^2 + 2\omega^3 + \omega^4 = 2\omega^3 + \omega^2 + \omega^4 = 2 \cdot 3 + \omega^2 + 3\omega = 6 + 3\omega + \omega^2$
- $x^3 = x \cdot x^2 = (\omega + \omega^2)(6 + 3\omega + \omega^2)$
  $= 6\omega + 3\omega^2 + \omega^3 + 6\omega^2 + 3\omega^3 + \omega^4$
  $= (3 + 9) + (6 + 3)\omega + (3 + 6)\omega^2 = 12 + 9\omega + 9\omega^2$
- 因为 $x = \omega + \omega^2$，所以 $x^3 = 12 + 9(\omega + \omega^2) = 12 + 9x$，即 $x^3 - 9x - 12 = 0$。
- **验证不可约性**：由有理根定理，$t^3 - 9t - 12$ 的可能有理根为 $\pm 1, \pm 2, \pm 3, \pm 4, \pm 6, \pm 12$，逐一检验均非根，故在 $\mathbb{Q}$ 上不可约。
- 又 $\deg = 3 = [\mathbb{Q}(\sqrt[3]{3}) : \mathbb{Q}]$，故 $t^3 - 9t - 12$ 即为 $x$ 的极小多项式。

**考法提示**：先确定一组线性无关基（如 $\omega = \sqrt[3]{a}$ 的 $1, \omega, \omega^2$）并算清乘法表；「把一切量在基下展开再比较坐标」可替代繁琐的直接化简；待定多项式的次数取最小可行值，并验证确不能再降。

**易错点**：展开 $x$ 的幂时漏掉交叉项导致系数算错；把更高次幂误当作仍在基内（应不断降幂归入基）；只解出候选多项式而不验证其确实满足目标条件；未验证不可约性就声称是极小多项式。

## 二、行列式

### 核心概念

- 行列式是 $n\times n$ 矩阵到基域的交错多重线性映射
- Vandermonde行列式：$\prod_{1\le i<j\le n}(x_j-x_i)$
- 特征多项式：$p_A(\lambda)=\det(\lambda I-A)$

### 常用公式

| 名称 | 内容 |
|---|---|
| Vandermonde | $\begin{vmatrix}1&1&1\\x_1&x_2&x_3\\x_1^2&x_2^2&x_3^2\end{vmatrix}=\prod_{i<j}(x_j-x_i)$ |
| 乘法公式 | $\det(AB)=\det(A)\det(B)$ |
| 转置不变 | $\det(A^T)=\det(A)$ |
| 换行变号 | 交换两行，行列式变号 |
| 行倍加不变 | 某行乘以常数加到另一行，行列式不变 |

### 标准解题步骤

**计算行列式：**
1. 观察结构：Vandermonde? 三对角? 分块?
2. 用行变换化简（优先行倍加，不改变行列式值）
3. Laplace展开或利用公式
4. 含参情形用试根法因式分解

### 常见陷阱

- 提取公因子注意：若 $k$ 行每行有公因子 $c$，提取的是 $c^k$
- Laplace展开时符号 $(-1)^{i+j}$ 容易遗漏
- 含参行列式展开后多项式因式分解出错

### 做题技巧

- 优先用行倍加制造零元素
- Vandermonde判别法：相邻两行是否成等比
- 含参行列式用试根法——代入小整数试探零点

### 应试解题技巧

- **配对乘积和与行列式下界**：行列式本质上是交错和 $\sum_{\sigma}\operatorname{sgn}(\sigma)\prod a_{i,\sigma(i)}$，涉及乘积配对。利用排序不等式可给出某些特殊矩阵行列式的下界估计：
  - 对正定对称矩阵 $A$，$\det A \le \prod a_{ii}$（Hadamard 不等式）
  - 利用 $\sum x_i^2 \ge \frac{1}{n}(\sum x_i)^2 = \frac{1}{n}\sum_{i,j} x_i x_j$ 可将平方和转化为配对乘积和

### 考试高频陷阱

- 提取公因子注意：若 $k$ 行每行有公因子 $c$，提取的是 $c^k$
- Laplace展开时符号 $(-1)^{i+j}$ 容易遗漏
- 含参行列式展开后多项式因式分解出错
- **配对乘积和混淆**：$\sum_{i \neq j} a_i a_j$（对称和）$= 2\sum_{i<j} a_i a_j$，两者相差因子 2。利用恒等式 $(\sum a_i)^2 = \sum a_i^2 + \sum_{i \neq j} a_i a_j$ 验证时容易漏掉这个因子

### 竞赛拓展：配对乘积和的不等式方法

**概念**：利用恒等式将平方和与配对乘积和联系起来，构造不等式链以求最值。

**核心恒等式**：
$$\sum_{i=1}^n a_i^2 = \frac{1}{n}\left(\sum_{i=1}^n a_i\right)^2 + \frac{1}{n}\sum_{1\le i<j\le n}(a_i - a_j)^2$$

**排序不等式**：设 $a_1 \le a_2 \le \cdots \le a_n$，$b_1 \le b_2 \le \cdots \le b_n$，则对任意排列 $\sigma$：
$$\sum_{i=1}^n a_i b_{n-i+1} \le \sum_{i=1}^n a_i b_{\sigma(i)} \le \sum_{i=1}^n a_i b_i$$
（逆序最小，同序最大）

**解题步骤**：
1. 将目标量表达为 $\sum a_i b_i$ 或 $\sum a_i^2$ 的形式
2. 选择适当的恒等式转化（平方和转配对和或反过来）
3. 利用排序不等式或 Cauchy-Schwarz 给出上下界
4. 取等条件确定最值

**易错点**：$\sum_{i\neq j}$ 与 $\sum_{i<j}$ 相差因子 2；排序不等式要求两序列同向排列，混用不同排序方向得到错误方向的不等式。

## 三、矩阵

### 核心概念

- **逆矩阵**：$A$ 可逆 $\iff \det A\neq0 \iff \operatorname{rank}A=n$
- **秩**：行（列）向量组的极大无关组个数
- **Jordan标准形**：矩阵在相似变换下的最简分块对角形式
- **对角化**：$A$ 可对角化 $\iff$ 每个特征值代数重数=几何重数
- **实对称矩阵**：必可正交对角化

### 常用公式

| 名称 | 内容 |
|---|---|
| 二阶逆矩阵 | $\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1}=\frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$ |
| 初等变换求逆 | $[A|I]\xrightarrow{\text{行变换}}[I|A^{-1}]$ |
| Sylvester不等式 | $\operatorname{rank}(A)+\operatorname{rank}(B)-n\le\operatorname{rank}(AB)$ |
| 同时对角化条件 | $AB=BA$ 且均可对角化 $\implies$ 可同时对角化 |

### 标准解题步骤

**求逆矩阵**：构造 $[A|I]$，行变换化 $[I|A^{-1}]$。二阶直接用公式。

**求秩**：行变换化行阶梯形，非零行数即秩。

**对角化判定**：
1. 求特征多项式，找所有特征值
2. 对每个特征值比较代数重数和几何重数
3. $d_i=n-\operatorname{rank}(\lambda_i I-A)$ 为几何重数

### 常见陷阱

- 初等变换求逆只允许**行变换**，不可混用列变换
- 行列式为零不能直接推出秩小于 $n-1$
- Jordan形中Jordan块的排列顺序不唯一，但块结构唯一

## 四、线性方程组

### 核心概念

- 齐次 $Ax=0$：有非零解 $\iff \operatorname{rank}(A)<n$
- 非齐次 $Ax=b$：有解 $\iff \operatorname{rank}(A)=\operatorname{rank}([A|b])$
- 基础解系：解空间的一组基，包含 $n-\operatorname{rank}(A)$ 个线性无关向量
- 通解 = 特解 + 齐次解

### 标准解题步骤

**求基础解系：**
1. 写出系数矩阵，行变换化行最简形（RREF）
2. 确定主元列和自由列
3. 自由变量依次取"1，其余取0"得到基础解系向量

### 做题技巧

- 优先用行变换而非Cramer法则
- 验证：将求得的基础解系代入原方程组检查

### 竞赛拓展：二元域与图状态的线性模型

**概念**：在 $\mathbb{F}_2$（模 2 算术的二元域）上，图上的边翻转操作可以表示为线性方程组，将图论问题转化为线性代数问题。

**核心原理**：
- 图的 $m$ 条边对应 $m$ 维 $\mathbb{F}_2$-向量，每条边翻转对应向量加法
- 边翻转操作构成 $\mathbb{F}_2^m$ 上的线性变换（因为 $1+1=0$，翻转两次回到原状态）
- 可达性问题转化为线性方程组 $Ax = b$ 在 $\mathbb{F}_2$ 上的可解性
- 解的个数为 $2^{m-\operatorname{rank}(A)}$

**关键区别（$\mathbb{F}_2$ vs $\mathbb{R}$）**：
- 加减法相同：$x+y = x-y$（因为 $y = -y$）
- 线性相关判定与实数域完全不同：$\{v_1, v_1+v_2\}$ 在 $\mathbb{F}_2$ 中可能相关
- Gaussian 消元在 $\mathbb{F}_2$ 中只需异或（XOR）操作

**解题步骤**：
1. 将图的状态编码为 $\mathbb{F}_2$-向量（0/1 表示状态）
2. 将操作表示为 $\mathbb{F}_2$-矩阵 $A$（每列对应一条边的翻转效果）
3. 解 $Ax = b$（目标状态方程），用 Gaussian 消元在 $\mathbb{F}_2$ 上求解
4. 若 $b \in \operatorname{Col}(A)$ 则可达成，解的个数由秩确定

**易错点**：二元域中 $1+1=0$，线性组合 $c_1v_1 + c_2v_2$ 只有 4 种可能（$c_i \in \{0,1\}$），与实数域的无穷多种组合完全不同；连分数展开在此处常用于奇偶性判定——将有理数表示为连分数后，其收敛性可用于判断 $\mathbb{F}_2$ 上的线性组合归宿。

## 五、二次型

### 核心概念

- **二次型**：$f(x)=x^TAx$，$A$ 为实对称矩阵
- **配方法**：通过配方化为平方和
- **正定性**：$f(x)>0$（$\forall x\neq0$）$\iff$ 所有顺序主子式 $>0$
- **惯性定理**：正、负惯性指数由二次型唯一确定

### 常用公式

| 判别法 | 内容 |
|---|---|
| Sylvester正定判别 | 所有顺序主子式 $>0$ |
| 惯性定理 | 规范形中正负平方项个数唯一 |
| 配方法 | 集中含某变量的项配方，逐次消去交叉项 |

### 标准解题步骤

**配方法**：
1. 若有平方项，集中配方
2. 若无平方项（所有 $a_{ii}=0$），用 $x_i=y_i+y_j, x_j=y_i-y_j$ 创造平方项
3. 得到 $f=d_1y_1^2+\cdots+d_ry_r^2$，正系数个数为正惯性指数 $p$

**正定性判别**：
1. 计算所有顺序主子式
2. 全正则正定
3. 或计算特征值，全正则正定

### 常见陷阱

- 正定性要求**所有顺序主子式**$>0$，不是所有主子式
- 配方法中线性替换必须**可逆**
- 半正定用顺序主子式 $\ge0$ 只是**必要**非充分条件

## 六、线性空间与线性变换

### 核心概念

- **基与维数**：极大线性无关组，$\dim V$ 唯一确定
- **坐标**：向量在基下的表示系数
- **核(Kernel)**：$\operatorname{Ker}(\sigma)=\{v:\sigma(v)=0\}$
- **像(Image)**：$\operatorname{Im}(\sigma)=\{\sigma(v):v\in V\}$
- **秩-零化度定理**：$\dim\operatorname{Ker}(\sigma)+\dim\operatorname{Im}(\sigma)=\dim V$

### 标准解题步骤

**求坐标**：解 $\beta=x_1\alpha_1+\cdots+x_n\alpha_n$ 得系数向量。

**求核空间**：解 $Ax=0$，解空间的基为核的一组基。

**证明线性无关**：设 $c_1v_1+\cdots+c_kv_k=0$，推导 $c_i=0$。

### 常见陷阱

- 坐标依赖于基的**次序**
- 核的维数 = $n-\operatorname{rank}(A)$，可用秩-零化度定理验证

### 竞赛拓展：max-plus 半格与向量闭包

**概念简述**：在 $\mathbb{R}^n$ 中，由向量加法与逐分量取 $\max$（或 $\min$）两种运算生成的闭包具有特殊的代数结构——它形成 max-plus 代数（热带代数，tropical algebra）下的半模（semimodule），同时具有格（lattice）与半格（semilattice）的性质。

**关键公式与定义**：
- Max-plus 加法：$a \oplus b = \max(a,b)$；Max-plus 乘法：$a \otimes b = a+b$（即普通实数加法）
- 向量闭包 $\operatorname{cl}(S)$：从有限生成集 $S=\{v_1,\ldots,v_k\}$ 出发，反复应用加法与 $\max$（逐分量）得到的所有向量的集合
- 有限生成性准则：若闭包可由有限个向量生成，则存在一组"极值向量"，闭包中所有向量均可由它们的 max-plus 线性组合 $\bigoplus_i (\lambda_i \otimes v_i)$（即 $\max_i\{\lambda_i + v_i\}$）表示

**解题步骤**：
1. 确定生成元集合 $S$，分析其元素在加法和 $\max$ 运算下的封闭性质
2. 判断闭包是否具有有限生成性——利用 max-plus 凸锥的有限生成定理（热带版本的 Carathéodory 定理）
3. 若闭包有限生成，寻找极小生成元组（类比线性空间的"基"，但不唯一）
4. 验证：任取闭包中一个向量，证明其可表示为生成元的 max-plus 线性组合

**易错点**：
- 普通线性空间中基的极小性和维数唯一性在 max-plus 结构中不复成立——极小生成元组一般不唯一
- $\max$ 运算不满足消去律：$\max(a,c)=\max(b,c)$ 不能推出 $a=b$
- Max-plus 代数中"线性无关"的定义与经典线性代数不同：一组向量 max-plus 无关，当且仅当每个向量都不可能由其余向量以 max-plus 方式生成

## 七、欧氏空间

### 核心概念

- **内积**：满足对称性、线性性、正定性的双线性型
- **Schmidt正交化**：逐次减去投影
- **正交变换**：$Q^TQ=I$，保持内积和长度

### 常用公式

| 名称 | 内容 |
|---|---|
| Schmidt正交化 | $\beta_k=\alpha_k-\sum_{i=1}^{k-1}\frac{\langle\alpha_k,\beta_i\rangle}{\langle\beta_i,\beta_i\rangle}\beta_i$ |
| 正交变换性质 | $(Qx)^T(Qy)=x^Ty$，$\det(Q)=\pm1$ |

### 常见陷阱

- 正交化过程中分母 $\langle\beta_i,\beta_i\rangle$ 不可为零
- 正交变换必须是**实**矩阵

## 八、特征值与对角化

### 核心概念

- **特征值/特征向量**：$Av=\lambda v$（$v\neq0$）
- **代数重数**：特征多项式根的重数
- **几何重数**：$\dim\operatorname{Ker}(\lambda I-A)$
- **可对角化** $\iff$ 对所有特征值代数重数=几何重数

### 常用公式

| 名称 | 内容 |
|---|---|
| 迹与行列式 | $\sum\lambda_i=\operatorname{tr}A$，$\prod\lambda_i=\det A$ |
| Cayley-Hamilton | $p_A(A)=0$ |
| 可逆与特征值 | $A$可逆 $\iff 0$不是特征值 |
| 逆阵特征值 | $A^{-1}v=\lambda^{-1}v$ |

### 做题技巧

- 三角矩阵特征值即主对角线元素
- 用迹和行列式验证特征值
- 对角化判定两步走：(1)特征多项式是否完全分解；(2)各特征值代数重数=几何重数?

## 九、通用解题方法论

### 矩阵问题统一框架

高等代数中超过70%的问题可归结为三类：

1. **标准形问题**：等价标准形(秩)、相似标准形(对角化/Jordan)、合同标准形(二次型)
2. **线性方程问题**：增广矩阵→行最简形→自由变量→基础解系
3. **不变性问题**：秩、行列式、迹、特征多项式、最小多项式

**拿到矩阵问题先问三问**：
1. 在什么变换下有意义？（等价/相似/合同？）
2. 在这种变换下什么量不变？
3. 能不能对角化？

### 验证方法速查

| 计算类型 | 验证方法 |
|---|---|
| 逆矩阵 | $A\cdot A^{-1}=I$ |
| 特征值 | $\sum\lambda_i=\operatorname{tr}A$ |
| 特征向量 | 代入 $Av=\lambda v$ |
| 基础解系 | 代入原方程组 |
| Schmidt结果 | 检查两两内积为零 |
| 秩 | 行阶梯形和列阶梯形各算一次 |

## 模块速查：配对乘积和的恒等式与最优下界
- 检索词：不等式 inequality 排列 permutation permutations 元组 tuples 实数 real numbers 乘积 product prod 配对 pairs 常数 constant 最小 minimum smallest 最大 largest 上界 upper 下界 lower 求和 sums 平方和 square 恒等式 identity 交替 alternating 构造 construction
- 核心内容：对实数元组，先把「两两乘积之和」改写为恒等式形式（全部元素和的平方减各元素平方和的一半），把目标下界问题转化为平方和的上界估计；当元组受「任意重排下相邻两项乘积之和恒不低于某常数」的约束时，先利用重排（排序）不等式确定使相邻乘积和取最小的排列（交替排列），由此导出各元素平方和的上界（不超过随元组长度线性增长的常数，即 4m−4 量级），再代回恒等式：因全部元素和的平方非负，两两乘积和 ≥ 负的平方和之半 ≥ 该上界之半的相反数，得到统一下界；最后处理等号可达性：需按元组长度逐一构造验证取等例子（如较小的长度可由交替取零与正负相间值的元组达到），不能默认同一构造对所有长度同时满足约束与取等。
- 解题路线：遇到「对所有排列均成立」的约束，先锁定最坏排列（交替排列）再全局化；最优常数类问题严格分「先证一般下界、再按长度逐一验证取等」两步；平方和与两两乘积和之间的恒等式是常用桥梁，代入前先确认平方和的界的方向（上界才能推出两两乘积和的下界）。
- 易错点：只证下界而漏构造取等例子，导致最优性不完整；默认统一构造对所有元组长度都同时取等（须逐长度验证）；最坏排列找错（应是比较相邻项乘积而非其他目标）；把「任意排列」误当「某一排列」，导致条件放缩方向错误；平方和的界方向写反（应取上界才能闭合论证）。
- 分步收尾：Σ_{p<q}c_pc_q=[(Σc)²−Σc²]/2；交替排列+排序不等式给 Σc²≤4m−4，代回得下界 2−2m；用 (2,0,−2,0,…) 周期构造验证取等。答案是 m 的表达式（2−2m 型），不是数值。

## 模块速查：函数方程的特殊值代入与多项式化
- 检索词：多项式 polynomial polynomials coefficient 函数方程 functional equation 递推 recurrence recursive
- 核心内容：对含两个变元的函数方程，先代入可消去一个变元的特殊值（如令某变元取零或单位值），得到关于单变元的约束，由此排除常值候选或确定关键初值；再对成对的特殊值（互为相反数）代入并作差，消去含对径点的项，得到递推关系，据此证明解必为多项式且次数受控；最后设成一般多项式、比较系数得有限组候选，并逐一回代验证。
- 解题路线：特殊值代入有顺序讲究——先消元、再定初值、再成对消项；「比较系数 + 回代验证」是多项式函数方程的标准收尾；充分性（候选确满足方程）与必要性（无其他解）都要写出。
- 易错点：代入特殊值后出现「乘积为零」分支时漏讨论因式分解的情形；比较系数前未先论证次数上界；只验证候选成立而漏证唯一性。

## 模块速查：有理数图上的边翻转传播与连分数约化
- 检索词：图上 graph 求值 evaluate 有理数 rational 实数 real 互异 distinct 奇偶 parity odd even 翻转 flip swap reverse 连分数 continued fraction 二染色
- 核心内容：当函数在有理数集上取值于二元域，且沿三类边（负运算、补运算、倒数运算）两端取值互异时，整个函数由单点初值沿图的连通性唯一确定；为计算任意有理数处的值，用连分数／Euclid 约化法：反复执行「减去整数部分（不改变函数值）」与「取倒数（翻转函数值）」两步直到常数，倒数操作的次数（奇偶）决定该点取值与初值的关系；最后把各点的值在二元域中求和。
- 解题路线：把三类约束建模为图的边，函数值沿边翻转等价于图的二染色；连分数展开中「取倒数」步骤数的奇偶是判定翻转与否的关键；多值求和按二元域奇偶规则进位。
- 易错点：「减整数部分」不翻转而「取倒数」翻转，两者混淆会导致奇偶性判反；漏掉先减整数部分直接数倒数次数；把二元域求和按十进制进位。

## 模块速查：对数微分与部分分式判定方程实根情况
- 检索词：多项式 polynomial polynomials coefficient 乘积 product prod 微分 differential derivative root roots 实数 real 互异 distinct 三次 cubic 常数 constants 重根 multiplicity
- 核心内容：对实系数多项式 F，先利用对数微分把 F 的一阶导与 F 之比展开为各根倒数的部分分式之和；对其再求导，由恒等式 (F′/F)′= (F″F−F′²)/F² 知 F″F−F′² = −F²·Σ 1/(z−α)²（即各 1/(z−α) 的平方和），对实变元恒为负；在单根处 F 取零而 F 的一阶导非零，同样可判定符号；于是含多项式及其一、二阶导乘积形式的方程在实数范围内无解的判定可以完全不依赖具体根值。
- 解题路线：见到含 F 与 F′、F″ 乘积结构的方程，优先尝试对数微分与部分分式；展开式各项平方和恒正或恒负决定判别式符号；需把「根处」与「非根处」分段讨论。
- 易错点：遗漏根处（F 取零但 F′ 非零）的单独讨论；把部分分式展开的符号方向写反；只在非根开区间讨论而漏掉根上取值。
- 判分口径衔接：上述恒负论证针对方程 f·f″ − (f′)² = 0（结论为无实根）；若题面问的是“实根个数的一切可能值”，官方题面第二个因子带系数 2（形如 (pz³+qz²+rz+s)(12pz+4q) = (3pz²+2qz+r)²，即 2f·f″ = (f′)²），此时恰有 2 个实根——见「解法直达·三次多项式 f·f″ 型方程的实根个数」，不得按 0 作答。

## 模块速查：多项式在参数变换下的不变量
- 检索词：多项式 polynomial polynomials coefficient 不变量 invariant 对称 symmetric symmetry

## 模块速查：对称多项式方程组的解结构与计数
- 检索词：多项式 polynomial polynomials 对称 symmetric symmetry 方程组 system equations 实数 real numbers 循环 cycle cycles ring 解 solutions 消元 elimination 结式 resultant 系数 coefficient 判别 discriminant

- **不等式必要条件的致命陷阱**：用 C-S/AM-GM 得到下界或等号条件后，等号饱和只覆盖让不等式取等的解（如 x²=y²=z²=1 的对称解）；严格大于/小于的情形必须另行求解或排除——不得把"等号成立当且仅当…"当成全部解。循环对称系统里非对称解通常严格满足所有不等式（不取等），只能用消元找到。
- **sympy 消元配方**：f1=x**2+y**2+z**2-3, f2=x*y**3+y*z**3+z*x**3-3；用 resultant 链消元：r1=resultant(f1,f2,x)（关于 x），r2=resultant(r1 与 f2 换成 y 的链），最终得到仅含 z 的一元多项式；再用 sp.nroots() 数实根个数（nroots 返回复数根，取虚部≈0 且互异去重者）。或直接 groebner([f1,f2], x,y,z) 后 nroots 数全部实解。有序三元组个数 = 互异实解个数；对称特解（各元相等）与一般解分别计数，一般解轨道 = 循环置换（×3）× 符号反转（×2）。
